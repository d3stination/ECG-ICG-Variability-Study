# Result files

`P1_Report.docx` is the unchanged 19-page supervisor report.

Each table uses one explicit observation unit:

- `detections.csv`: one dataset-condition-point-method stratum, with valid, missed, invalid and upstream-ineligible counts together.
- `reference_accuracy.csv`: one participant-method reference summary on the stated strict common-reference sample.
- `variability.csv`: one participant-method disagreement summary on common-valid beats.
- `conditions.csv`: one matched-condition method-outcome summary.
- `condition_participant_changes.csv`: one participant-method matched change used to produce `conditions.csv`.
- `morphology_continuous.csv`: one dataset-condition-method-outcome-feature continuous test.
- `morphology_categories.csv`: one higher-versus-lower participant-relative morphology contrast.
- `condition_morphology.csv`: one matched morphology-change versus reliability-change test.
- `failure_mechanisms.csv`: one verified primary failure-reason stratum.
- `bland_altman.csv`: one paired method comparison.
- `waveform_examples.csv`: one reproducibly selected waveform case.
- `dataset_references.csv`: one dataset-condition-point reference and coverage audit row.

The figure folders contain only the 27 PNGs used to support the final report narrative. Plotting CSVs are not mixed with the public-facing images.
